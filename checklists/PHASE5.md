# Phase 5 Checklist — Autonomy & Rituals (Dawn Circle, Alignment, 1:1s)

**Reference:** [`docs/05-phase-5-autonomy-and-rituals.md`](../docs/05-phase-5-autonomy-and-rituals.md)

- [ ] Dawn Circle create cron installed (`--no-agent` with `dawn-circle-create.py`)
- [ ] Dawn Circle close cron installed (`--no-agent` with `dawn-circle-close.py`)
- [ ] Both scripts are executable and their state dir is writable; run them once
      manually with `DAWN_CIRCLE_DATE=YYYY-MM-DD` to verify create → close without
      waiting for the schedule
- [ ] The Circle card body carries the three-line format and etiquette rules
- [ ] At least one agent posted a real three-line check-in, and the card closed cleanly
- [ ] Weekly alignment cron exists; at least one alignment report exists under
      `Research/alignment/` with the 4 sections (shipped, stuck, judgment gaps, state
      changes)
- [ ] The human (or operator) actually reads/acknowledges the alignment reports — if the
      agent reports theater is not a success
- [ ] A peer-review / 1:1 happened at least once (two agents, one question, a position
      each, a synthesis), either via a facilitated board task or delegation
- [ ] A collaboration-pattern choice was made consciously for at least one task:
      solo vs pair vs swarm, with the seam named

**Verification output to capture:** manual create→close run output, one Dawn Circle card
with ≥1 agent comment, one alignment report, one 1:1 outcome comment.

**Done when:** rituals run on schedule, agents check in and self-audit for real, and at
least one peer discussion produced a better decision.
